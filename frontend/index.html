About GameGroup

GameGroup is a tiny site dedicated to helping my local board gaming group keep track of our games, organize events, and manage our memberships. It's built with Python on the backend and Brython on the frontend, using PostgreSQL for data storage. This project is open-source and available on GitHub. Feel free to explore the code, contribute, or suggest features!
